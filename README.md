# Sis Adası — 3D Adventure v2.0

Bu sürüm v1.0 dikey diliminin üzerine genişletilmiş oynanabilir 3D macera sürümüdür.

### Yeni / geliştirilmiş sistemler
- Daha yoğun 3D ada ve çevre dağılımı
- Üçüncü şahıs kamera ve mobil/PC kontrolleri
- 3 vuruşluk kombo saldırı sistemi
- Sis Darbesi özel yeteneği
- Düşman takip AI'ı ve elit Koruyucu
- Büyük Koruyucu boss altyapısı
- 6 aşamalı görev akışı
- NPC, kule, Işık Çekirdeği ve Sis Kapısı hikâye noktaları
- Daha güçlü atmosfer, ışıklandırma, parçacıklar ve çevre
- Sağlık/dayanıklılık, sprint ve yeniden doğma
- Kayıt/devam etme ve pause sistemi
- Mobil HUD/joystick

## Çalıştırma
```bash
npm install
npm run dev
```

> Not: Bu paket kod tarafında tam bir oynanabilir prototip/dikey dilimdir. Gerçek ticari/AAA kalite için sonraki aşamada harici lisanslı 3D karakter/animasyon varlıkları, özgün ses/müzik, daha ayrıntılı çevre modelleri ve daha kapsamlı içerik eklenmelidir.
